# 🩺 Breast Cancer Diagnosis Using Deep Learning

A Flask-based web application for breast cancer diagnosis using deep learning models trained on pathological image datasets.

---

## 📌 Project Overview

Breast cancer is one of the leading causes of cancer-related deaths among women worldwide. Early diagnosis significantly improves treatment outcomes.

This project uses deep learning models to classify pathological breast cancer images and predict whether the sample is cancerous.

The application provides an easy-to-use web interface where users can upload an image and receive an instant prediction.

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/aksharagaddam49-web/Breast-Cancer-Diagnosis.git
```

Move into the project

```bash
cd Breast-Cancer-Diagnosis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
